# CheatChek
Назначение: Автоматическая диагностика и проверка параметров системы.
Требования: Обязательный запуск от имени администратора (с правами суперпользователя). Без повышенных привилегий утилита не сможет получить доступ к защищенным системным разделам, службам и журналам событий, что приведет к ошибке или неполным результатам проверки.


Инструкция по запуску:
1. Нажмите правой кнопкой мыши на файл automaticcheck.
2. Выберите пункт «Запуск от имени администратора».
3. Дождитесь окончания работы скрипта и появления отчета.
